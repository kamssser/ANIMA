# edu-motion-studio

Skill milik pemilik HyperForge (dibuat dengan bantuan ChatGPT), boleh disertakan di installer.
Dipasang ke `~/.claude/skills/edu-motion-studio` bersama HyperForge Studio (`EDU_SKILL` di `electron/skills.cjs`,
penanda = hash isi folder). Dipakai penuh oleh style Explainer Datar; aturan HyperForge di brief menang bila bertentangan
(penutup tuntas + terima kasih, narator santai, visual Explainer Datar).
